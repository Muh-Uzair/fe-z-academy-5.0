# Z-Academy 5.0 - Sidebar Navigation Structure

## Overview

Application uses role-based sidebar navigation. Each user role (Admin, Instructor, Student) will have different menu items according to their permissions.

---

## 1. ADMIN SIDEBAR

- Dashboard
- Courses
  - All Courses
  - Pending Courses
  - Verified Courses
- Instructors
  - All Instructors
  - Pending Verifications
- Students
- Enrollments
- Categories
- Revenue & Payouts
- Settings

## 2. INSTRUCTOR SIDEBAR

- Dashboard
- My Courses
  - All My Courses
  - Create New Course
  - Pending Verifications
- My Students
- Enrollments
- Earnings
- Chat
- Settings

## 3. STUDENT SIDEBAR

- Dashboard
- Browse Courses
- My Learning
  - Enrolled Courses
  - Continue Watching
- Chat
- Settings
